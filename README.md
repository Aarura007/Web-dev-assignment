# 💸 Student Expense Tracker

A colourful and responsive web application that helps students manage daily expenses, track spending, and organize transactions by category.

## ✨ Features

- ➕ Add new expenses with name, amount, and category.
- 📊 Calculate total expenses automatically.
- 🔢 Display total number of transactions.
- 🗑️ Delete expenses easily.
- 🔍 Filter expenses by category.
- ⚠️ Input validation for empty and invalid values.
- 📱 Responsive and attractive user interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the website.
- **CSS3** – Styling, gradients, animations, and responsive design.
- **JavaScript** – DOM manipulation and expense management.
